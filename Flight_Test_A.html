Flight Test A

What to fly and what to check for the first test flight of this Edward build. Every test point says what the feature is, what to do, and what counts as a pass. You report the results in a form with the same numbers, setting each point to Passed, Not passed or Not tested.

⚠ First, in the flying mission (Part 1): set the Directional Gyro

The Mosquito's Directional Gyro (the dial marked “DIRECTION INDICATOR” on the main panel) is not connected to the compass, so after you enter the aircraft it can show any heading. Edward gives every heading as a magnetic heading, so his calls only make sense once the gyro agrees with the magnetic compass.

  1. Straight after entering the cockpit, fly straight and level for a few seconds and read the heading on the magnetic compass.
  2. Turn the Directional Gyro Adjustment Control Knob, just below the dial, until the Directional Gyro shows the same heading.
  3. Check it against the compass again about every 15 minutes; the gyro slowly drifts.

What Edward is

Edward is the navigator in the right-hand seat of the DCS Mosquito F.B. Mk. VI. He calls out headings and times, keeps the fuel cocks right, arms the bombs and works the bomb bay on a bomb run, and can hold the aircraft on a course and altitude for you. You talk to him through a ring menu: press e in flight. Every wedge of that menu is explained in The Edward Menu.

Words used on this page

  • Hold (menu Hold My Aircraft): Edward holds the aircraft on a set course and altitude. You fly the aircraft yourself in this test; use Hold only where a test point asks for it.
  • Steer call: Edward's on-screen line telling you the course to fly, for example “Two minutes to WP2. Steer 095°M, range 8.1 NM.”
  • dcs.log: DCS's log file, Saved Games\<your DCS folder>\Logs\dcs.log. Some points ask you to search it for a line of text after the flight: open it in a text editor and use Find. DCS starts a new log each time it starts, so check it (and keep a copy for the report) before starting DCS again.

Before you start

  1. Install the test build (run Install.bat) and restart DCS.
  2. In flight, menu Status ▸ Logging: set it ON. The log checks below need it.
  3. Menu Settings ▸ Automations: set everything ON.
  4. In the cockpit of the flying missions (Parts 1 and 3): set the Directional Gyro to the magnetic compass (see the box at the top of this page).
  5. Fly Part 2 before Part 3: Part 3 uses the landmarks you make in Part 2.

Part 1 — Mission FlightA-High: the turn calls

You start heading 183° magnetic, so first set the Directional Gyro to 183 (see the box at the top). Fly the route to WP3; the bomb run after it is not part of this test.

1.1 “Turn now” comes before the waypoint

What Edward calls each turn before the waypoint, worked out for a 30° bank turn (the first mark on the bank indicator) at your present speed, so you roll out on the line to the next waypoint instead of overshooting it.

Do Watch the range to WP1 on the Navigation page as the turn call comes. Do the same at WP2 and WP3.

Pass “Turn starboard now for heading … New track …” (or port) comes before each waypoint: about half a mile out for a gentle turn, a little over a mile for a right-angle turn, more for a sharper one. After the flight, dcs.log has one line turn point for WP1, and the same for WP2 and WP3. In the notes, write the range shown when each call came.

Part 2 — Mission DRSurvey: making the landmark points

Edward calls out landmarks (towns, churches, bridges…) as you pass them. He finds them in a one-time survey of the map, which you make here. You start on the ground and the heading doesn't matter, so there is no need to set the Directional Gyro.

2.1 Making the survey: saving shows a result on the menu

Do Open Navigation ▸ DR Landmarks and click Create DR Points. Wait about a minute until the survey is done, then click Save.

Pass The centre of the page shows SAVED n + 0 YOURS (n is the number of landmarks found).

Part 3 — Mission FlightA-Landmarks: landmarks saved with the mission

Needs Part 2 first. Each time you load a mission in single player, Edward picks landmarks along the route of every Mosquito flight in it and saves them into a copy of the mission, named mission_navpoints.miz, in the same folder. In that copy the landmarks are ordinary navigation points, which is how they reach every player in multiplayer. Set the Directional Gyro first (see the box at the top).

3.1 Landmarks saved with the mission

Do Load Edward-FlightA-Landmarks.miz and take the slot.

Pass Once you are in the cockpit (not hidden behind the loading screen): “EDMod: DR landmarks for 2 flights saved to Edward-FlightA-Landmarks_navpoints.miz - host that file in multiplayer.” That file is now in the same folder as the mission. Leave the mission.

3.2 Landmarks show as nav points

Do Load Edward-FlightA-Landmarks_navpoints.miz and take the slot. Look at the F10 map, then open Navigation ▸ DR Landmarks.

Pass The landmarks show on the map with plain names, along your route and along the other flight's route, with no second Edward mark on top of them. The DR Landmarks page shows Landmarks on Your Route (n).

3.3 Landmark calls along the route

Do Fly the route in this _navpoints mission.

Pass About a minute before each landmark on your route, a heads-up call (“Pinpoint in one minute - …”), then a fix call as it passes (“There is …”, with how early or late you are and which side of the track). About one landmark every 20 NM, roughly every 5 minutes. In the notes: could you see each one, and did early/late and the side of track match what you saw?

3.4 A landmark of your own

Do On the F10 map, place a mark a few minutes ahead, no more than 2 NM from your route line, with the text FP - Test. Don't touch the menu.

Pass About a minute before you reach it, a heads-up call for “Test”, then a fix call as you pass, each once. Edward draws no mark of his own over yours.
